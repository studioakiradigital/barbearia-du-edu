Declaração de Privacidade

Esta Declaração de Privacidade foi atualizada pela última vez em 11/11/2026 e se aplica a cidadãos e residentes legais permanentes do Brasil, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 – LGPD).

Nesta Declaração de Privacidade, explicamos como coletamos, utilizamos, armazenamos e protegemos os dados pessoais obtidos por meio do nosso site. Recomendamos que você leia atentamente este documento.

No tratamento de dados pessoais, cumprimos todos os requisitos previstos na legislação brasileira de proteção de dados, o que significa, entre outros pontos, que:

  • informamos de forma clara as finalidades para as quais os dados pessoais são tratados;
  • limitamos a coleta de dados pessoais ao mínimo necessário para finalidades legítimas;
  • solicitamos consentimento expresso do titular sempre que exigido por lei;
  • adotamos medidas técnicas e administrativas adequadas para proteger os dados pessoais;
  • respeitamos os direitos dos titulares de dados, permitindo acesso, correção ou exclusão quando solicitado.

Caso tenha qualquer dúvida ou deseje saber exatamente quais dados mantemos sobre você, entre em contato conosco.

1. Finalidade, dados coletados e período de retenção

Podemos coletar ou receber dados pessoais para diversas finalidades relacionadas às nossas atividades comerciais, incluindo, mas não se limitando a:

1.1 Contato

Dados coletados:

  • Nome ou apelido
  • Endereço de e-mail
  • Número de telefone

Base legal para o tratamento:
Consentimento do titular e/ou legítimo interesse.

Período de retenção:
Os dados serão mantidos enquanto forem necessários para o atendimento da solicitação ou enquanto durar a relação entre as partes.

1.2 Análise e melhoria do site

Para compilar e analisar estatísticas de uso do site e melhorar a experiência do usuário.

Dados coletados:
Dados de navegação (como páginas acessadas, tempo de permanência, endereço IP)

Base legal para o tratamento:
Legítimo interesse.

Período de retenção:
Os dados serão mantidos pelo período necessário para cumprir as finalidades descritas ou conforme exigido por lei.

1.3 Oferta de produtos e serviços personalizados

Dados coletados:

  • Nome ou apelido
  • Endereço de e-mail
  • Número de telefone

Base legal para o tratamento:
Consentimento do titular.

Período de retenção:
Os dados serão mantidos até que o titular solicite a exclusão ou revogue o consentimento.

2. O que acontece se você não fornecer seus dados pessoais?

Caso você opte por não fornecer determinados dados pessoais, pode ser que não consigamos fornecer informações, produtos ou serviços solicitados.

3. Cookies

Nosso site utiliza cookies para melhorar a experiência do usuário. Para mais informações sobre o uso de cookies, entre em contato conosco pelos canais informados ao final desta Declaração.

4. Compartilhamento e divulgação de dados

Os dados pessoais poderão ser divulgados:

  • quando exigido por lei ou ordem judicial;
  • em resposta a autoridades públicas competentes;
  • no caso de reorganização societária, fusão, aquisição ou venda de ativos, hipótese em que os dados poderão ser transferidos aos novos responsáveis.

Não comercializamos dados pessoais.

5. Segurança dos dados

Estamos comprometidos com a proteção dos dados pessoais. Adotamos medidas de segurança técnicas e organizacionais adequadas para prevenir acessos não autorizados, uso indevido, perda ou divulgação indevida de informações.

6. Sites de terceiros

Esta Declaração de Privacidade não se aplica a sites de terceiros acessados por meio de links em nosso site. Recomendamos que você leia as políticas de privacidade desses sites antes de fornecer quaisquer dados pessoais.

7. Alterações nesta Declaração de Privacidade

Reservamo-nos o direito de alterar esta Declaração de Privacidade a qualquer momento. Recomendamos que você consulte este documento periodicamente para estar ciente de eventuais atualizações.

8. Direitos do titular de dados

Nos termos da LGPD, você possui os seguintes direitos:

  • confirmação da existência de tratamento de dados;
  • acesso aos dados pessoais;
  • correção de dados incompletos, inexatos ou desatualizados;
  • anonimização, bloqueio ou exclusão de dados desnecessários ou excessivos;
  • portabilidade dos dados, mediante solicitação expressa;
  • eliminação dos dados tratados com consentimento;
  • informação sobre o compartilhamento de dados com terceiros;
  • revogação do consentimento.

Para exercer seus direitos, entre em contato conosco pelos canais informados ao final desta Declaração.

9. Reclamações

Caso não esteja satisfeito com o tratamento de seus dados pessoais, você pode apresentar reclamação à Autoridade Nacional de Proteção de Dados (ANPD):

Autoridade Nacional de Proteção de Dados (ANPD)
Esplanada dos Ministérios, Bloco C, 2º andar

10. Crianças e adolescentes

Nosso site não é direcionado a crianças ou adolescentes. Não coletamos intencionalmente dados pessoais de menores de idade. Caso identifiquemos a coleta indevida, os dados serão excluídos.
